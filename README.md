## Skills

You can find examples of the described skills in the [Examples of my work](#examples-of-my-work) section.

__Foundational Knowledge__
  * Software Development Life Cycle (SDLC): A clear understanding of the entire software development process, from requirements to deployment and maintenance.
  * Software Testing Life Cycle (STLC): Knowledge of the phases of testing, including planning, analysis, design, execution, and closure.
  * Agile and Scrum Methodologies: Familiarity with modern development frameworks and how a QA tester fits into a collaborative, iterative team.
    
__Test analysis & design__
  * Reviewing requirements and specifications: Carefully examining the functional and non-functional requirements, design documents, and user stories.
  * dentifying test conditions: Breaking down the requirements into individual, testable conditions.
  * Evaluating testability: Assessing whether the requirements are clear, unambiguous, and can actually be tested. If a requirement is vague, i seek  clarification from the development team or product owner.
  * Prioritizing test conditions: Ranking the identified test conditions based on their risk, importance, and complexity.

__Testing Techniques & Types__
  * Test Case Design: The ability to write clear, concise, and effective test cases from requirements or user stories.
  * Test Design Techniques: Proficiency in techniques such as Equivalence Partitioning, Boundary Value Analysis, Decision Table Testing, and State Transition Testing to create comprehensive test scenarios.
  * Functional Testing: Verifying that a software system performs as per the functional requirements.
  * Regression Testing: A core manual testing skill, ensuring that new code changes have not negatively impacted existing functionality.
  * Non-Functional Testing: Basic knowledge of performance, usability, and security testing.
  * Cross-Browser and Cross-Platform Testing: The ability to test applications across different browsers (Chrome, Firefox, Safari) and operating systems (Windows, macOS, mobile platforms).
  * Exploratory Testing: The skill of performing unstructured, unscripted testing to discover unexpected issues and gain a deeper understanding of the system
